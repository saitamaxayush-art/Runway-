# Runway

Runway financial runway and expense tracker application.

## Project Structure

- `frontend/`: React + Vite single page application
  - `frontend/src/`: Application source code (components, styles, entry point)
  - `frontend/index.html`: Entry HTML
  - `frontend/vite.config.js`: Vite configuration

## Getting Started

### Development
From the root directory:
```bash
npm run dev
```

Or from the `frontend` directory:
```bash
cd frontend
npm install
npm run dev
```

### Production Build
```bash
npm run build
```
